# إستراحة أهل الأثر

موقع ثابت (HTML/CSS) + نماذج شاشات التطبيق.

- `index.html`: الموقع الرئيسي (ذهبي، بحركات CSS)
- `screens/`: الشاشة الرئيسية، الجدول، الأرشيف، صفحة القسم (نماذج بحجم الجوال)
- `assets/logo.jpg`: شعار إستراحة أهل الأثر

لا يحتاج أي بناء: افتح `index.html` في المتصفح.
النصوص بين أقواس مثل [التاريخ] و[عنوان الدرس] أماكن مؤقتة.
.
